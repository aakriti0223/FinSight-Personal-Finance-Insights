# FinSight — Personal Finance Insights

**A full-stack personal finance management application**

FinSight is a web-based personal finance application designed to help users manage transactions, track income and expenses, and understand their financial activity through useful insights.

## Key Features

- **Transaction Management:** Manage and organize financial transactions.
- **Income and Expense Tracking:** Monitor financial inflows and outflows.
- **Financial Summaries:** View summarized financial information.
- **Responsive Interface:** Access the application through a React-based user interface.
- **REST API:** FastAPI-powered backend for transaction and summary operations.
- **Database Integration:** PostgreSQL database with SQLAlchemy.
- **Containerized Deployment:** Docker-based application setup.

## Technology Stack

| Layer | Technologies |
|---|---|
| Frontend | React, JavaScript, Vite, CSS |
| Backend | Python, FastAPI, Pydantic |
| Database | PostgreSQL, SQLAlchemy |
| API Communication | Axios |
| Deployment | Docker, Docker Compose, Nginx |
